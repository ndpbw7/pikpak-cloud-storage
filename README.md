## 링크 클라우드 저장, 도대체 어떻게 되는 건가

일반 클라우드 저장과 링크 클라우드 저장의 차이는 단순하다.

- **일반 클라우드**: 내 기기로 파일 먼저 다운로드 → 그걸 다시 업로드
- **링크 클라우드 저장**: 링크만 붙여넣으면 → 서버가 직접 파일을 가져와서 내 클라우드에 저장

쉽게 말해, 클라우드 서버가 내 대신 다운로드 일을 해주는 것이다. 내 기기 배터리도 안 쓰고, 내 인터넷 속도도 안 쓰고, 내가 잠든 사이에 다 끝나 있다.

지원하는 링크 종류가 다양할수록 쓸모가 커진다. PikPak의 경우 현재 이런 것들을 지원한다:

- 토렌트 파일 및 마그넷 링크
- HTTP 직접 다운로드 링크
- X(구 Twitter), 틱톡, 페이스북 등 SNS 영상 URL
- ED2K 링크
- 텔레그램 봇을 통한 파일 전송

링크 하나 붙여 넣으면 픽팍 서버가 분석해서 내 개인 클라우드에 담아준다. 80% 이상의 파일은 몇 초 안에 완료된다고 한다. 실제로 시드가 많은 토렌트 파일은 거의 즉시 저장되는 경험을 하는 유저들이 많다.

## 핵심 기능 뜯어보기

### 초고속 링크 저장 (클라우드 다운로드)

PikPak이 내세우는 건 '20배 빠른 저장 속도'다. 왜 가능하냐면, 다운로드가 내 기기에서 일어나는 게 아니라 PikPak의 기업용 네트워크 인프라에서 일어나기 때문이다. 대역폭이 아예 다른 수준이라 일반 가정 인터넷으로 받는 것보다 훨씬 빠르다.

또 하나 흥미로운 점은, 같은 파일이 이미 PikPak 서버에 존재할 경우 그걸 그냥 가져오는 방식으로 작동한다는 것. 그래서 인기 있는 파일은 시드 수에 상관없이 거의 즉시 저장되기도 한다.

### IP 보호 (VPN 없이도 프라이버시)

토렌트나 마그넷 링크를 쓸 때 신경 쓰이는 게 내 IP가 피어들에게 노출되는 것인데, PikPak의 경우 다운로드가 PikPak 서버에서 일어나기 때문에 피어들에게는 PikPak 서버 IP만 보인다. 내 IP는 노출되지 않는다. 모든 서버 통신도 암호화 프로토콜로 처리되어 ISP도 내가 무엇을 저장했는지 확인할 수 없다.

### 4K 온라인 스트리밍

저장된 영상은 앱이나 웹에서 바로 스트리밍이 가능하다. 유튜브처럼 화질 옵션이 자동으로 제공되고, 4K 원본 화질도 지원된다. HDR도 앱 최신 버전에서는 지원한다. 다운로드 없이 바로 재생되니 스마트폰 용량 걱정도 없다.

### 텔레그램 봇 연동

텔레그램에서 @PikPak_Bot에 링크나 파일을 보내면 자동으로 내 PikPak에 저장된다. 텔레그램을 많이 쓰는 사람이라면 특히 유용한 기능이다.

### 멀티 플랫폼 접근

Android, iOS, Windows 앱, 웹 브라우저, Chrome/Edge 확장 프로그램, Android TV, WebDAV 클라이언트까지 지원한다. rclone으로 PC에 가상 드라이브로 마운트하는 것도 가능하다. macOS 앱은 개발 중이라고 공식적으로 밝힌 상태다.

### 클라우드 압축 해제

ZIP, RAR, 7z 파일은 클라우드에서 직접 압축 해제가 가능하다. 10GB짜리 ZIP 다운로드 후 압축 풀기라는 과정을 건너뛸 수 있다.

**이동 중 스트리밍형**: 호텔 와이파이나 이동 중 LTE 환경에서 파일을 다시 다운로드하는 게 아니라 PikPak에서 바로 스트리밍. 어디서든 속도는 PikPak 서버 기준이다.

**rclone/Alist 파워유저형**: PikPak을 rclone이나 Alist와 연동해서 Windows 탐색기에 가상 드라이브로 마운트하거나 WebDAV 클라이언트로 접근하는 고급 사용법. 스트리밍 성능도 꽤 쓸 만하다고 평가한다.
